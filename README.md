# Lid

Releases of Lid.app, the menu-bar app (and `lid` command) for our OpenBao. Signed and notarized; the source is private.

Download the latest: https://github.com/1023-Ventures/lid-releases/releases/latest

Unzip it, move Lid.app to Applications and open it. An invite link (lid://join?…) opens its Set Up window. You'll also need WireGuard from the App Store.
